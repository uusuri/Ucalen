**Subscription Management Platform**

A Spring Boot-based REST API application designed to help users track and manage their digital subscriptions efficiently. The platform allows authenticated users to:

- **Add subscriptions** with details such as subscription name, expiration date, price, and billing information
- **View all active subscriptions** linked to their account
- **Track subscription expenses** through a centralized dashboard

**Key Features:**
- User authentication and authorization via Spring Security
- RESTful API endpoints for subscription CRUD operations
- Automatic subscription data persistence using Spring Data JPA
- Secure user identification based on authenticated sessions

**Target Use Case:**
Perfect for users who manage multiple digital services (streaming, software licenses, cloud storage) and need a centralized way to track costs and renewal dates.

---

**Tech Stack:** Java, Spring Boot, Gradle, Spring Security, Spring Data JPA
